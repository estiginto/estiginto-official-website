# ESTIGINTO Website

Vite + React static website for the ESTIGINTO official site.

## Requirements

- Node.js 20 or newer
- npm

## Install

```bash
npm ci
```

## Run Locally

```bash
npm run dev
```

Vite prints a local URL, usually:

```text
http://localhost:4302/
```

## Debug

The contact page provides direct email, telephone, and LINE links in the shared
footer. It does not contain an inquiry form or an email-draft workflow.

The latest page inventory and verification record is in
`docs/project-takeover-2026-09-05.md`.

Use the browser DevTools first:

- Console: React/runtime errors
- Network: missing images or failed asset paths
- Elements: layout and CSS inspection
- Lighthouse: performance and SEO checks

Useful commands:

```bash
npm run build
```

Builds the production site into `dist/`. Run this before pushing if you changed React code, assets, or build config.

```bash
npm run preview
```

Serves the built `dist/` output locally. Use this to test the same shape Vercel will deploy.

## Public Entrypoints

The production build contains the following standalone HTML entrypoints:

```text
index.html       Main official website
about.html       About page
solutions.html   Solutions page
case.html        Case studies
consulting.html  Consulting page
faq.html         FAQ page
contact.html     Contact page
map.html         Interactive map experience
Oasis/           Published Oasis guide subsite
```

## Project Structure

```text
*.html                  Vite HTML entries and page-specific metadata
src/main.jsx            Official-site React bootstrap
src/App.jsx             Official-site content and React components
src/App.css             Official-site styling
src/map/                Interactive map application
Oasis/                  Standalone guide subsite copied into production
img/                    Public marketing images
tests/                  Node contract and behavior tests
scripts/copy-static.mjs Copies approved static assets into dist
scripts/verify-dist.mjs Checks production output and asset limits
vercel.json             Vercel build/output/cache config
```

## Deploy To Vercel

Vercel should use:

```text
Build Command: npm run build
Output Directory: dist
```

These are already configured in `vercel.json`.

## Notes

- Do not commit `node_modules/` or `dist/`.
- Browser captures, Playwright CLI state, and temporary PDF renders belong in
  `output/`, `.playwright-cli/`, and `tmp/`; these paths are intentionally ignored.
- `dist/` is generated by `npm run build`.
- The root HTML files are production entrypoints for distinct routes and SEO metadata.
- `npm run check` is the complete local verification command.
