# 官網文案修訂

## 目的與準則

將官網訪客可見文案改為清楚、得體、可協助判斷的企業服務介紹。使用「我們／您」，說明服務內容與合作方式，避免反駁客戶、宣傳空話、工程展示標籤或未經確認的成果承諾。保留公司、團隊、聯絡資料、服務能力、既有案例事實；需求表單維持移除。

範圍：7 個官網入口、中英日文案、共用選單、區塊標籤與 HTML 描述。map、Oasis、未掛載的歷史元件不改版。沿用 codex/remove-contact-form 的工作目錄，不覆蓋原 checkout 未提交變更。使用者於修訂完成後授權「更新上去」，包含提交及發布至 origin/master。

## 範圍邊界

FAQ 是原有內容的編輯整理，沒有新增價格、付款比例、免費服務、交付權利或商業成果保證。移除缺乏專案條件的廣泛價格與工期區間，改為說明評估依據。客戶定位以使用者確認的國際五星級酒店等級企業為準，重視品牌一致性、服務體驗、跨市場協作與交付責任；不擅自宣稱特定酒店客戶或未有佐證的服務成果。原有「較業界優惠」「AI 節省 70%」缺乏本次可核對的佐證，不沿用為公開宣稱。合約事項只說明應確認的範圍，不增寫法律判斷。

## 驗證方式

檢查三語資料對應、公開區塊實際掛載、頁面與 HTML 描述一致、舊文案殘餘；執行既有測試與建置。以 terminal Playwright 核對每頁三語與桌機／手機，特別檢查 FAQ 翻譯、收合和副標長度。

## 驗證結果（2026-09-05）

- npm run check：207 項測試、正式建置與 200 個產物檢查通過。
- Terminal Playwright：7 頁 × 3 語 × 2 尺寸（1440／390 px），42 組 HTTP 200、單一主標、共用頁尾、無水平溢出，未發生 pageerror。
- 合作說明：各語系與尺寸皆為 3 組 12 題，逐題展開成功；英文主內容無中文回退。新增語系 ID 對應與答案翻譯回歸測試。
- 聯絡頁：所有語系與尺寸均無表單。另以截圖人工檢視中文手機首頁與桌機聯絡頁，文字未遭裁切。
- 最後統一日文合作說明導覽名稱、關於與服務頁 metadata 後，再次通過 npm run check。
- 既有 map bundle 大於 500 kB 警告仍在，本次文案修訂未處理地圖效能。工程檢查不等同品牌文案已獲客戶認可。
- 發布從 codex/remove-contact-form 執行；原 checkout 的既有變更完整保留。master 原為本分支祖先，可快轉更新遠端預設分支，不操作原 checkout 的髒檔。

## 本次回顧

後續使用者指出「專業服務與精選實績」並非原站區塊。這是接手時自行新增的 PageNextSteps 延伸導覽，已從關於、解決方案、案例、顧問及合作說明五頁移除，刪除元件及相關樣式；保留原有頁尾與手機服務選擇樣式。上方表格描述的是先前已發布版本，不代表此項新增獲得使用者認可。

前一輪把工程可用性檢查當成文案品質檢查，並新增使用者不需要的表單。修正原則：先確定訪客需要知道什麼，再寫文案；功能驗證與編輯品質分開回報，不用自評高分代替使用者判斷。
