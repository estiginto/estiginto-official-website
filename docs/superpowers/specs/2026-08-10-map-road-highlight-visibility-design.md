# 地圖道路高亮辨識度調整設計

## 目標

讓使用者在深色 2D 與 3D 地圖中能立即辨識被選取的整段道路，同時維持電影 HUD 視覺，且不讓高亮看起來像導航路線。

## 視覺方案

採用三層道路線條：深色寬幅襯底、青色寬幅外光、近白青色核心線。襯底把道路從建築與底圖切開；外光提供遠距辨識；核心線保留道路的精準位置。縮放時三層寬度皆使用插值，避免低縮放過粗或高縮放過細。

道路仍使用整體呼吸動畫，不加入方向箭頭、虛線或移動光點，以免暗示導航與路線規劃。動畫最低亮度提高並遵守 reduced-motion；使用者停用動態效果時仍保有完整靜態對比。

## 驗收條件

- 2D 與 3D 模式中，道路高亮均明顯高於周圍道路與建築。
- 道路名稱與地圖標籤仍可閱讀。
- 高亮維持連續線條，不呈現導航方向。
- 桌機與 390px 手機畫面皆無 HUD 遮擋或水平溢位。
- 現有建築／區域高亮、指南針與搜尋互動不受影響。
- 圖層契約測試、完整測試與正式建置通過。
