# 地圖幾何高亮與指南針設計

## 目標

讓使用者選取搜尋結果後，不只看到單一定位點，也能依 OpenStreetMap 的真實幾何資料辨識完整道路、建築或大型區域。同時加入可顯示方位並一鍵回正的 HUD 指南針，且將頂部模式標籤簡化為「2D」與「3D」。

## 範圍

- 道路：顯示搜尋道路的完整可辨識線段，不建立導航或行駛路線。
- 建築、園區、公園與行政區等面狀地點：顯示真實 Polygon 或 MultiPolygon 邊界。
- 純座標地點：保留既有雷達定位點，不以半徑推測不存在的範圍。
- 指南針：顯示目前北方，點擊後回到正北；3D 模式保留俯視角度。
- 頂部模式切換：文字只顯示「2D」與「3D」。
- 保持免費、免金鑰、免環境設定，並維持現有搜尋與 RWD 行為。

## 資料流程

1. Photon 繼續負責文字搜尋，正規化結果時保留 `osm_type` 與 `osm_id`。
2. 使用者選取結果後，幾何服務才發出一次邊界請求，不做自動完成或背景批次查詢。
3. 面狀物件以 OSM 物件識別碼取得完整 GeoJSON 幾何。
4. 道路以名稱、物件識別碼與選取座標解析相連或同名的道路線段，避免只顯示單一節點。
5. 結果以 OSM 識別碼快取；新選取會中止舊請求，過期回應不得覆蓋目前目標。
6. 外部幾何服務失敗、回傳不支援的資料或沒有邊界時，畫面保留定位點且搜尋仍可正常使用。

## 地圖圖層

MapLibre 使用單一 GeoJSON source，依幾何類型疊加下列圖層：

- 道路外光：較粗、低透明度的青色 line layer。
- 道路核心：較細、較亮的青白色 line layer。
- 區域填色：半透明深青色 fill layer，不遮蔽底圖資訊。
- 區域外框：雙層青色 line layer，形成電影 HUD 光暈。
- 選取動畫：一般模式在鎖定時播放一次亮度脈衝；偏好減少動態效果時停用動畫。

切換搜尋結果時更新同一個 source，避免持續新增圖層。清除目標時改為空 FeatureCollection。

## 鏡頭與互動

- 有有效幾何邊界時，以 padding 避開桌面左右資訊面板或手機底部面板後 fit bounds。
- 只有 Point 時沿用既有 fly-to 與雷達標記。
- 道路或區域仍保留中央目標標記，方便辨識搜尋結果的代表位置。
- 2D／3D 切換不得清除目前高亮幾何。

## 指南針與位置

- 使用 MapLibre NavigationControl，只啟用指南針，不顯示縮放按鈕。
- 關閉 pitch 視覺化，因此點擊只重設 bearing；3D 俯視角度不會被重設。
- 桌面放在中央地圖區右上角、搜尋框下方且位於目標資料面板左側。
- 手機放在右側、底部資訊面板上方，避開 safe area。
- 按鈕採圓形 HUD 刻度、青色光暈與北向箭頭；觸控尺寸至少 48px。
- 無障礙名稱使用「將地圖轉回正北」，鍵盤可操作並具有清楚焦點樣式。

## 錯誤、限制與資料政策

- 幾何解析是漸進增強；失敗不得讓地圖進入錯誤頁。
- 公共服務請求只由使用者選取觸發、依序執行並快取，遵守每秒最多一次請求的限制。
- 保留 OpenStreetMap attribution。
- OSM 中沒有建模為線或面的地點只能顯示 Point，介面不宣稱已取得完整邊界。
- 道路可能由多個同名 OSM way 組成；只保留選取位置附近且與目標名稱相符的部分，避免誤選遠方同名道路。

## 測試與驗收

- 單元測試：OSM 識別碼正規化、幾何 URL、Point／LineString／Polygon／MultiPolygon、無效資料、快取、中止與錯誤退回。
- 地圖設定測試：圖層順序、顏色、透明度、無路線圖層、指南針選項。
- UI 合約測試：頂部只顯示 2D／3D、指南針無障礙名稱與 RWD 安全位置。
- 瀏覽器測試：搜尋道路與大型地點、幾何高亮、清除、更換結果、2D／3D 保留高亮、旋轉後點擊指南針回正。
- 桌面與手機皆確認無遮擋、無錯誤覆蓋層，並檢查相關 console error。
