# 入場動畫實驗室設計

## 目的

建立一個只供本機評選的獨立頁面，一次展示三種未來感入場動畫。頁面不加入 Vite 正式建置入口，也不修改首頁、導覽或既有頁面轉場。

## 展示方向

### A. 沙丘式降臨

先以近乎全黑的停頓建立尺度感，接著出現遙遠地平線、漂浮沙塵與低頻光脈衝。品牌文字像巨型結構從霧中浮現，最後由一道狹長垂直光縫揭開內容。節奏緩慢、厚重、具有儀式感。

### B. Doctor Who 式穿越

以同心時空隧道、星點拉伸、色差殘影與不穩定時間刻度構成穿越感。畫面先向前加速，再突然失重並折回，品牌文字在不同時間位置短暫重影，最後鎖定成清晰介面。

### C. 混合式時空降臨

前半段採用沙丘式寂靜與巨大地平線，中央結構開始出現不可能的空間折疊後，轉入短促的時間漩渦。漩渦不是飛離畫面，而是向中央坍縮成一道門，網站內容像從另一個座標抵達。這是建議優先整合到正式網站的方向。

## 頁面與操作

- 路徑：`prototypes/motion-lab/`
- 三款動畫在同一頁以分頁或選擇器切換，共用一個主舞台。
- 提供「播放／重播」、「上一款／下一款」與聲音開關。
- 初始聲音關閉，必須由使用者手動開啟，以符合瀏覽器自動播放限制。
- 動畫結束後停在同一個簡化品牌首頁畫面，方便直接比較入場過程，而不是比較三套落地頁設計。
- 顯示每款名稱、體感關鍵字與大約時長，但控制介面不干擾動畫舞台。

## 技術方案

採用原生 Canvas 2D 產生沙塵、星點、隧道與扭曲場，CSS 負責遮罩、排版、色差、光縫與內容揭露；不增加第三方套件。音效由 Web Audio API 程序生成低頻、脈衝與空間噪聲，不加入外部音訊素材。

實作拆成獨立 HTML、CSS 與 JavaScript。JavaScript 以共用播放控制器管理生命週期，每款動畫擁有自己的 `start`、`render`、`stop`，切換時清除 animation frame、計時器與音訊節點，避免重播後疊加。

## 動態與可用性

- 桌機與手機都能觀看；Canvas 依裝置像素比調整，但限制高解析度上限以控制效能。
- 背景分頁或切換動畫時暫停繪製。
- `prefers-reduced-motion` 開啟時，以短暫淡入與靜態構圖取代高速穿越及大幅縮放。
- 所有按鈕可鍵盤操作，動畫舞台標記為裝飾性內容。

## 驗證

- 確認本機 Vite 能直接開啟實驗頁。
- 確認 `npm run build` 不會把實驗頁加入正式輸出入口。
- 測試三款動畫可重播與連續切換，且不殘留 Canvas、計時器或聲音。
- 測試聲音預設關閉、手動開啟後正常播放，並確認 reduced-motion 模式。

## 非目標

- 不使用電影畫面、角色、Logo、配樂或其他受版權保護素材。
- 本輪不整合到正式首頁，也不決定最後採用哪一款。
