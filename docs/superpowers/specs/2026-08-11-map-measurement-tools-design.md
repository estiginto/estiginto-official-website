# 地圖測繪工具設計

## 目標

在現有真實世界互動地圖加入兩種可直接操作的測繪工具：可拖曳調整的圓形範圍，以及兩點之間的直線最短距離與道路行徑距離。所有功能維持免費、免 API Key、免環境設定。

## 工具與互動

### 圓形範圍

- 使用者先啟用「範圍」工具，再於地圖點擊中心。
- 系統建立預設 500 公尺半徑的半透明青色圓形。
- 圓周上的琥珀色把手可直接拖曳，拖曳時即時更新圓形大小。
- 資訊卡顯示半徑、直徑、圓周長與面積；距離依大小自動使用公尺或公里，面積使用平方公尺或平方公里。
- 再點地圖可重設中心；清除按鈕移除所有測量內容。

### 兩點距離

- 使用者啟用「距離」工具後，依序點擊 A、B 兩點。
- 第一點建立後，HUD 提示選擇第二點；第二點建立後立即顯示直線最短距離。
- A、B 皆為可拖曳把手；拖曳後同步更新直線距離與道路行徑查詢。
- 直線使用較細的白青色虛線；道路行徑使用寬青色外光與琥珀色核心，使行徑距離成為主要視覺焦點。
- 道路行徑採駕車模式，顯示行徑距離與預估時間，不提供逐向導航或路線規劃流程。

## 資料與計算

- 圓形、圓周把手與直線距離皆在瀏覽器本機計算，不傳送額外資料。
- 球面距離使用 haversine 公式。
- 圓形 GeoJSON 使用以中心、半徑與固定 96 個頂點產生的 Polygon。
- 道路行徑使用 OSRM Route service 的 driving profile，請求 `overview=full&geometries=geojson&steps=false`，讀取最快行徑的 geometry、distance 與 duration。
- OSRM 公開服務無 SLA；請求失敗、逾時或無道路時保留 A/B 與直線距離，資訊卡顯示「暫時無法取得行徑距離」並提供重試。

## 元件邊界

- `measurementGeometry.js`：純函式，負責 haversine、圓形、把手位置、格式化與 GeoJSON 組裝。
- `travelDistance.js`：封裝 OSRM URL、回應驗證、AbortSignal 與逾時。
- `MeasurementTools.jsx`：工具列與資訊卡，只處理顯示和按鈕事件。
- `MapExperience.jsx`：持有工具模式、圓形與兩點狀態，協調道路行徑請求。
- `WorldMap.jsx`：把 MapLibre 點擊與拖曳事件轉成座標事件，渲染測量 source/layers/markers。

## 版面與可及性

- 桌機工具列置於搜尋框下方中央，不遮擋左右資訊面板。
- 手機工具列置於搜尋框下方，指南針下移；資訊卡置於地圖下方但高於既有 bottom sheet。
- 工具按鈕使用 `aria-pressed`，狀態與測量結果使用 live region。
- 啟用工具時地圖游標改為 crosshair；拖曳把手時仍可使用滑鼠與觸控。
- reduced-motion 下停用測量線條脈衝，但保留完整視覺對比。

## 驗收條件

- 圓形中心可由地圖點擊決定，圓周把手能直接改變大小。
- 半徑、直徑、圓周與面積數值會隨拖曳即時更新。
- 兩點建立後同時顯示直線最短距離與道路行徑距離。
- 行徑路徑視覺強度高於直線，且 A/B 拖曳後會重新計算。
- 道路服務失敗不會清除直線距離。
- 工具可清除、切換，且不破壞搜尋、地標高亮、2D／3D、指南針與 RWD。
- 桌機與 390px 手機完成實際操作 QA。
