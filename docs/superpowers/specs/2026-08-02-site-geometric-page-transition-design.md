# 全站幾何掃描轉場設計規格

## 目標

為 ESTIGINTO 全站站內頁面切換建立一致的幾何掃描轉場，並補強手機菱形選單的開啟與關閉動畫。動態風格延續既有深藍、三角與菱形語彙，呈現精準、克制的科技感，不加入霓虹粒子、隨機光點或常見 AI 生成式視覺。

## 套用範圍

轉場套用至所有同網域、會前往另一個 HTML 頁面的站內連結，包括：

- Logo 與頁首導覽。
- 桌機與手機選單。
- 頁面內容按鈕與文字連結。
- 頁尾導覽。

以下連結維持瀏覽器原生行為，不攔截：

- 同頁 `#` 錨點。
- 語言切換按鈕。
- `mailto:`、`tel:` 與外部網址。
- 帶有下載屬性、非左鍵點擊或按住 Ctrl、Command、Shift、Alt 的新分頁操作。
- `target="_blank"` 連結。

瀏覽器上一頁、下一頁與直接載入網址只執行新頁揭露，不偽造離場動畫。

## 頁面轉場

### 離場

使用固定於視窗最上層的轉場覆蓋元件。使用者點擊合格站內連結後：

1. 被點擊的連結短暫進入啟動狀態。
2. 上下兩片深藍斜切幾何面板向中央閉合。
3. 一條細藍掃描線沿閉合邊界通過。
4. 覆蓋完整後才設定 `window.location.href`，避免切頁早於動畫。

離場約 500ms，需防止連續點擊造成重複導頁。若目的地與目前網址實際相同，不啟動轉場。

### 進場

每個 HTML 入口在 React 掛載後共享同一轉場元件。初始畫面由覆蓋狀態開始，兩片面板向外退開，掃描線同步淡出，主要頁面內容以極小幅度上移並恢復清晰。進場約 400ms；離場與進場合計體感約 900ms。

若 JavaScript 尚未執行或失敗，頁面內容仍須可見，不能由靜態 HTML 預設永久遮蔽。

## 手機選單動畫

沿用現有三角觸發器、中央菱形與五個導航項目，不改變資訊架構與位置。

開啟時：

1. 背景遮罩在 260ms 內淡入並加入輕度模糊。
2. 中央菱形由縮小與輕微旋轉狀態展開，主動畫約 520ms。
3. 五個選單項目以 60ms 間隔依序淡入與位移復位。
4. 字級控制在導航項目之後出現。
5. 三條選單線平滑變形成關閉符號。

關閉時使用相反順序收回，保留元素直到退場完成，避免突然消失。選單開啟期間仍鎖定背景捲動。

手機選單中的站內連結被點擊時，先提供約 120ms 的選取回饋，再直接銜接頁面離場覆蓋；不必完整等待選單關閉動畫，以免操作拖沓。

## 實作結構

新增一個專責的全站轉場元件與一個判斷站內連結是否可攔截的純函式。元件以事件委派監聽文件上的點擊，不逐一修改所有連結，也不改成單頁應用路由。

轉場狀態分為 `entering`、`idle`、`leaving`。目的地只在 `leaving` 覆蓋完成後導向。動畫完成以 `animationend` 為主，另設同長度的受控計時器作為保險，並設置單次導頁保護。

手機選單沿用既有 React `open` 狀態，增加供退場與選項錯開動畫使用的狀態 class；不引入動畫套件或新依賴。

## 可用性與效能

- 覆蓋元件在閒置時不可攔截指標事件。
- 轉場層使用 `transform` 與 `opacity`，避免以寬高驅動動畫。
- 導航期間維持鍵盤與輔助科技可理解的原生連結結構。
- `prefers-reduced-motion: reduce` 下取消斜切移動與交錯效果，改成最長 120ms 的淡入淡出，並縮短導頁等待。
- 頁面轉場的 `z-index` 高於語言提示、手機選單與其他固定元件。
- 不新增音效、震動或自動播放媒體。

## 測試與驗證

- 純函式測試涵蓋站內頁面、同頁錨點、外部網址、電話、Email、下載、新分頁與組合鍵點擊。
- 元件契約測試確認三種轉場狀態、單次導頁保護、全站掛載與 reduced-motion 樣式。
- 手機選單契約測試確認五個項目具有交錯延遲、關閉反向動畫與選取後銜接轉場。
- 執行完整測試、正式建置與靜態檔案驗證。
- 桌機與手機實際檢查所有主要站內導覽路徑，確認不閃白、不重複導頁、不產生水平溢位。
- 檢查上一頁、下一頁、新分頁、Email、電話、外部連結與頁內錨點仍維持預期行為。
- 三種語言與手機 120% 字級下檢查轉場及選單，瀏覽器主控台不得有錯誤。

## 完成標準

所有站內跨頁連結皆以一致的幾何掃描動畫離場，新頁以反向幾何動畫揭露；手機選單開關與選項具有完整且可逆的分層動畫；原生連結能力、無障礙偏好與既有導覽行為不受破壞，整體轉場體感約 900ms。
