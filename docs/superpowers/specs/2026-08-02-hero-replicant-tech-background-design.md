# Hero 機械介面動態背景設計規格

## 目標

為首頁 Hero 建立具有《尼爾：人工生命》高階視覺語彙的機械介面動態背景：米白紙質感、低彩度黑灰線條、幾何圓環、刻度、座標與殘缺資訊。設計只借用抽象氣質，不複製遊戲圖片、字體、Logo、角色、圖示或原始介面。

Hero 動態需與全站幾何掃描轉場及手機選單動畫共用相同的色彩、線條和時間節奏，形成一套一致的動態系統。

## 視覺構成

動態背景由四個獨立層次組成：

1. **基底網格**：沿用目前 88px 網格，降低對比並加入細微紙面噪點，維持米白背景。
2. **機械圓環**：在 Hero 右側配置大型不完整同心圓、刻度與十字準星，避免壓在主要標題下方。
3. **資料標記**：加入少量座標、序號、短線與自製殘缺字碼，例如系統狀態、時間碼與幾何索引；內容不使用遊戲專有名詞。
4. **掃描與錯位**：一條低對比掃描線週期性通過右側構圖，局部線段偶爾短暫錯位，形成機械訊號感。

所有裝飾元素設為 `aria-hidden="true"`，不進入可讀內容與鍵盤順序。

## 動畫節奏

採中等強度，但優先保護文字閱讀：

- 外圈以 28 秒完成一圈，內圈以 22 秒反向旋轉。
- 掃描線每 9 秒通過一次，實際可見時間不超過 1.4 秒。
- 資料標記以 12–18 秒週期進行 4–10px 的緩慢垂直漂移。
- 局部錯位每 7 秒至 11 秒觸發一次；每次只作用於單一裝飾片段，維持 100–160ms，不讓整頁閃爍。
- 滑鼠移動只在桌機產生最大 12px 的背景視差，使用 `requestAnimationFrame` 合併更新。
- Hero 標題、說明與捲動提示不參與持續視差，保持穩定。

動畫在頁面幾何揭露完成後才開始，避免進場轉場與 Hero 背景同時爭奪注意力。

## 響應式設計

### 桌機

大型圓環集中於畫面右側約 42% 區域。標題所在左側保留乾淨底色，只允許極淡網格與少量細線穿過。

### 手機

圓環縮小並移至右上與右下邊緣，保留裁切感，不使用裝置方向或陀螺儀。資料標記數量減半，視差停用，掃描線與慢速旋轉保留。不得遮擋標題、語言選擇器、三角選單與捲動提示。

## 實作結構

新增一個只負責裝飾的 `HeroTechBackground` React 元件，由 `Hero` 掛載。元件使用內嵌 SVG 繪製圓環、線段、刻度與文字標記，CSS 控制旋轉、漂移、掃描與局部錯位。

桌機指標視差封裝為獨立 hook 或小型 effect，只更新 Hero 根節點上的 CSS 自訂屬性 `--hero-parallax-x` 與 `--hero-parallax-y`。元件卸載時必須取消 animation frame 並移除事件監聽。

不使用 Canvas、影片、圖片素材、第三方動畫套件或新依賴。現有 Hero 文案與內容結構不變。

## 與其他動畫的協調

- 頁面轉場覆蓋層的 `z-index` 高於 Hero 所有裝飾。
- 手機選單與語言提示高於 Hero 背景。
- Hero 進場延遲至幾何頁面揭露完成；若無轉場狀態事件，最遲於頁面掛載後 900ms 啟動。
- 從首頁離場時，Hero 動畫不額外播放結束效果，由全站幾何覆蓋層統一收尾。
- 三套動畫共用 `--ease-soft`，但持續背景動畫使用線性或平滑往返節奏，不使用彈跳。

## 可用性與效能

- `prefers-reduced-motion: reduce` 時停用旋轉、漂移、掃描、錯位與視差，只保留靜態幾何背景。
- 所有持續動畫只使用 `transform` 與 `opacity`。
- 頁面在背景分頁或 `document.visibilityState !== "visible"` 時，CSS 動畫暫停；回到前景後恢復。
- 裝飾層使用 `pointer-events: none`，不能阻擋 Hero 連結與捲動。
- 手機不得出現水平溢位，120% 字級下構圖仍不可碰撞主要文字。
- 不加入閃爍頻率高於每秒三次的效果。

## 測試與驗證

- 契約測試確認 `HeroTechBackground` 只在首頁 Hero 掛載，且所有裝飾均為輔助科技隱藏。
- 測試指標視差只在精細指標裝置啟用，並確認事件與 animation frame 可清理。
- 樣式契約確認圓環、掃描線、漂移、局部錯位與 reduced-motion 靜態模式存在。
- 執行完整測試、正式建置與靜態檔案驗證。
- 桌機檢查滑鼠視差、掃描週期、標題可讀性與頁面轉場銜接。
- 手機檢查 390px 寬度、三種語言、120% 字級、三角選單開啟與背景動畫並存情況。
- 確認無水平溢位、無主控台錯誤，且外觀不依賴任何遊戲素材。

## 完成標準

首頁 Hero 在不影響文案閱讀與網站效能的前提下，呈現清楚可辨識的米白機械介面科技感；桌機具有細微視差，手機維持精簡動態；減少動態效果時完整退化為靜態背景；並能與全站幾何轉場及手機選單動畫自然銜接。
